# SpeedGrader Helper

This is a Chrome extension that makes your grading experience with the ~~"old and obsolete"~~ Canvas SpeedGrader _infinitely_ better.

## Features

With this extension, you can...

- Apply and manage reusable rubric items for each question.
- Apply and manage reusable comments.
- Turn on focus mode with the selected questions for an immersive experience.
- Import and export rubric profiles to share rubric items.
- Take advantage of the handy action items for each question.
- Use and customize keyboard shortcuts for navigation and other grading actions.
- Forget about entering invalid points.
- Work with a ~~lovely-~~ okay-looking UI for managing your grading session.
- ...
