# Workflow

## Overview

SpeedGrader Helper works by "intercepting" the flow of Canvas SpeedGrader to enhance your grading experience.
This means that SpeedGrader Helper will attempt to modify the SpeedGrader page to

1. add more features (e.g., grading/navigation controls, hotkeys),
2. override functionality (e.g., custom grading feedback submission flow, auto-submit on navigation),
3. suppress undesired behaviour (e.g., [this weird behaviour](./grading#weird-behaviour-note)).

SpeedGrader Helper keeps the workings of Canvas SpeedGrader intact and helps you streamline your grading workflow.

## User flow

The use of SpeedGrader Helper is straightforward.

1. Load the Canvas quiz that you wish to grade, either directly from SpeedGrader or via Canvas' open API. See the following section for more details.
2. Configure the rubrics for questions in the UI. Export and share the rubrics with other graders.
3. Go to the SpeedGrader page for the quiz to begin grading.
