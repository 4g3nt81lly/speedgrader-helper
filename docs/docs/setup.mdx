# Setup

## Get started

The extension requires very minimal setup.

1. [Download Google Chrome](https://www.google.com/chrome) if you haven't already. If you've already installed Chrome, make sure the version number is **at least 125** (go to [chrome://settings/help](/) to check your version). The latest version is _preferred but not required_.
2. Go to [Chrome Web Store]() and click on "Add to Chrome" to install the extension.

That's it! The extension is ready to use! Feel free to pin the extension for easier access.

### Canvas Integration

If you wish to use the extension with Canvas integration, follow the steps below:

1. [Generate a Canvas access token.](https://community.instructure.com/en/kb/articles/662901-how-do-i-manage-api-access-tokens-in-my-user-account#add-access-token)
2. Open the extension options page. Alternatively, open the extension page in the side-panel or in a new tab and navigate to the `Settings` tab.
3. Scroll down to the **Integrations** section and enter both your Canvas domain (e.g., `https://canvas.instructure.com`) and your access token.
